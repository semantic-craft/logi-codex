## Release notes

0.1.5 introduces a paper-white Ring background, black action glyphs, and a new white terminal-style plugin icon. The eight actions are unchanged.

For the white theme, set Icon Color to 171717 in Options+. Use Apply to multiple with only Icon Color selected for the eight Codex actions. Options+ can override SVG colors with a stored profile Icon Color. Existing profiles may retain their previous top application icon after an update.

macOS only; MX Master 4 for Mac.
